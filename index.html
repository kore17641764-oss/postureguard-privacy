한국어

PostureGuard(이하 "앱")는 사용자의 개인정보를 수집·저장·전송하지 않습니다.

  • 데이터 수집 없음: 앱은 이름, 이메일, 위치, 연락처 등 어떠한 개인정보도 수집하지 않습니다.
  • 서버 전송 없음: 앱은 인터넷으로 어떤 데이터도 전송하지 않습니다. 네트워크 권한을 사용하지 않습니다.
  • 블루투스 사용 목적: 이미 사용자의 휴대폰에 페어링된 무선 이어버드에 연결하여, 이어버드의 헤드트래킹(움직임) 센서 값을 기기 내부에서만 읽어 자세를 판정하는 데에만 사용됩니다. 이 데이터는 저장되거나 외부로 전송되지 않으며, 실시간 판정 후 폐기됩니다.
  • 로컬 저장 항목: 사용자가 설정한 임계 각도·지속 시간·경고음·스트레칭 알림 주기 등 설정값만 기기 내부 저장소에 저장되며, 외부로 전송되지 않습니다.
  • 제3자 공유 없음: 어떠한 데이터도 제3자와 공유하지 않습니다.
  • 광고·분석 도구 없음: 광고 SDK나 분석 도구를 포함하지 않습니다.

English

PostureGuard (the "App") does not collect, store, or transmit any personal data.

  • No data collection: The App does not collect any personal information such as name, email, location, or contacts.
  • No network transmission: The App does not send any data over the internet and does not request network permissions.
  • Bluetooth usage: Used solely to connect to wireless earbuds already paired with the user's phone, in order to read the earbuds' head-tracking (motion) sensor values on-device only for posture detection. This data is never stored or transmitted and is discarded after real-time evaluation.
  • Local storage: Only user preferences (threshold angle, duration, alert sound, stretch-reminder interval) are stored on the device and are never transmitted.
  • No third-party sharing: No data is shared with third parties.
  • No ads or analytics: The App contains no advertising SDKs or analytics tools.
